# valnic-media

Imágenes **aprobadas** para publicar en Instagram [@valnic.spa](https://instagram.com/valnic.spa).

- `posts/NN-slug/`: láminas en JPEG (y `reel.mp4` en los reels).
- `cola.json`: posts aprobados, con su fecha y texto. Las rutinas de publicación lo leen.

Este repositorio lo actualiza automáticamente `automatizacion/preparar-publicacion.mjs`. No editar a mano.
